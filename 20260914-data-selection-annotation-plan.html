論点 1 / 4

データセットを固定カメラの映像に絞るか

案得られるもの懸念
固定カメラに絞る（82本、43試合）コートのキャリブレーションが1本に1回で済む。視点がそろい、モデルの性質が安定しやすいカメラが動く映像に弱くなり、アプリケーションとしての汎用性が下がりうる
追従も含める（111本、56試合）カメラが動く映像も学習と評価の対象になるコートの基準点をフレームごとに推定する必要がある。

いまの案は折衷である。 研究の最初の段階では固定カメラに限り、アプリのデモでは次のように扱う。

  • カメラが動いたかを、固定カメラ判定の信号処理で判定する
  • 構え直しの映像は、構図が変わる時点で切って分割する
  • カメラが動き続ける映像の場合、「精度が下がる場合がある」と注意書きを出す

Future Workとしてカメラが動く場合も対応させる。

アノテーションを付ける区間

Astraは優秀だがtoken消費が激しい。そこで2段階に分ける。 Astra の下書きを人が直して少数フレームに bbox を付け、それで RF-DETR を Fine-Tuning し、その出力を人が直す。 イベント（セットプレー・交代）時刻は43試合の全体に付ける。

02アノテーション

bboxの下書きを何に作らせ、人がどこを直すか

下書きの3手法を同じ10秒で比べる

4試合の10秒（5 fps で50フレーム）に、3手法で下書きを付けた。

手法枠と ID の作り方役割
Deep-EIoUYOLOX-x ＋ OSNet（SportsMOT で学習）なし
Astra 1枚ずつ1依頼に画像1枚。ID は特徴点追跡で結ぶ選手、GK、審判
Astra 複数フレーム1つの会話で11枚を続けて読み、枠と ID を書く選手、GK、審判
  • Deep-EIoU は見逃し、控えの誤検出などが多い
  • Astra 1枚ずつは遠くのGKの除外、審判が誤って3人検知、見逃しなどがある
  • Astra 複数フレームは取り違えが最も少ないが、トークン消費が大きい。

目視での比較で、精度は測っていない。

アノテーションの流れ

人は下書きを直すだけで、枠を一から描かない。

会場ごと（15会場）

  1. 人
    コート線をアノテーション（16の基準点を結ぶ）
  2. 抽出
    会場ごとに3秒 × 20本の区間を選ぶ
  3. Astra
    3秒×5fps=15枚をastraに渡してbbox推論
  4. 人
    15フレームすべてのbboxを直し、RF-DETRのFTデータに
RF-DETR を Fine-Tuning Astra+人で直したbboxを用いてFTする。必要に応じて公開フットサルデータ（画像）も使う。

試合ごと（43試合）

  1. RF-DETR + ByteTrack
    試合全体にbboxとID予測
  2. 人
    ID の切れ目や人数の合わないフレームを機械的に選び、優先して直す
  3. ルール 人
    イベント（セットプレー、交代）時刻の候補を出し、試合を通して見て直す
  4. 人
    セットプレーと交代を含む（且つ難解な）連続5分を選ぶ
  5. 人
    5分の区間の bbox と ID を 5 fps で直し、間を補完して元の fps で目視で確かめる
論点 3 / 4

段階1 の bbox で Fine-Tuning するモデルを、会場ごとに作るか、1つの汎用モデルにするか

単位得られるもの懸念
会場ごと（15モデル）その会場の床の色、照明、カメラの角度に合わせた下書き1会場300フレームで足りるか未確認。モデルが15個になる
1つの汎用モデル（15会場 ＋ Roboflow の公開画像）4,500フレームに公開画像を足せる。未学習の会場での精度を測れる会場ごとの量が偏る。公開画像は視点とクラス定義が違う

いまの案は汎用モデルで、公開画像を入れるかは最初の3会場の学習曲線で決める。

Astra のトークン消費

中央大の10秒での比較。 複数フレームは読んだ画像が会話に積み上がるので、入力が約60倍になる。 段階1 では1本の15フレームを1依頼で渡し、積み上がりを避ける。

3秒クリップの下書きに要る週の枠（複数フレーム、ChatGPT Plus の週単位）

15フレームを1依頼で渡す形（1本 約0.7〜0.9%、未実測の見積もり） Plus の1週分

見積もりは docs/annotation_protocol.md の付録（1枚ずつの依頼103件の実測から換算、再試行分1割を加算）。

論点 4 / 4

研究室で Codex を契約できないか

300本の下書きに Plus で約2.4〜3.0週かかる。 Pro（枠5倍、月100ドル）なら1週に収まるが、個人では高い。
